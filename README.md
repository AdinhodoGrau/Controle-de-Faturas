# 📊 Controle de Faturas

Mini web app para controle operacional de faturas de energia.

## 🚀 Funcionalidades
- Acompanhamento por status:
  - AGUARDANDO
  - RECEBIDA
  - VALIDADA
  - ENVIADA
- Dashboard com indicadores rápidos
- Filtro por status
- Atualização manual de status

## 🛠️ Tecnologias
- Python
- Streamlit
- Pandas

## ▶️ Como rodar localmente

```bash
pip install -r requirements.txt
streamlit run app.py
